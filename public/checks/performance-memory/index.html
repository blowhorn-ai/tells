Performance memory pings

Group: fingerprint. Since v0.2.0. Catalog 1.0.3.

What Tells reads

  • performance.memory samples (used, total, limit) taken alongside the latency pings

How the result is decided

  • Pass: Every sample is physically plausible.
  • Warning: At least one sample contains impossible heap values.
  • Not available: This browser does not expose performance.memory. Only Chromium browsers do, so Firefox and Safari always read Not available here. That is normal.

Findings

  • performance_memory_anomaly: medium, 12 points. since v0.2.0
